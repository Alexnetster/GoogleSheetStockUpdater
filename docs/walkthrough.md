# 주식 데이터 갱신 및 월별 투자 일지 시스템

자동화된 주식/코인- **갱신날짜**: 데이터가 마지막으로 업데이트된 일시 (YYYY-MM-DD HH:MM:SS)
시트/캘린더 연동 시스템 **v2.1.0** 완료

## 🌟 최신 업데이트 (v2.1.0)


### 1. NXT 거래소 시간대 완벽 대응 🆕

- **신규 스케줄**: 08:01 AM (미장 마감/오전), 12:01 PM (국장 오전/미드데이), 16:00 PM (국장 마감), 20:01 PM (NXT 마감/이브닝)
- **NXT 세션 감지**: 08:00~20:00 KST 사이 실행 시 국장 데이터를 강제 활성화하여 수집
- **미장 마감 반영**: 오전 08:01 실행 시, 전일 날짜로 마감된 미장 데이터를 "오전 브리핑"으로 간주하여 자동 병합 수집
- **주의종목 관리**: '특이종목' 명칭을 '주의종목'으로 변경하고, 시간대별로 누적하여 리포트 생성

### 2. 제로 하드코딩 및 종목 분류 도입 (v2.4.2) 🆕

- **`Category` 필드**: `관심종목_요청` 시트에서 종목의 성격을 직접 지정합니다.
  - `Index`: 시장 지수 및 환율 (KOSPI, S&P500 등)
  - `Major`: 핵심 대형주 (리포트 주요 섹션에 표시)
  - `Watchlist`: 시세 알림 및 분석용 관심 종목
- **지수 동적 관리**: 이제 소스 코드를 수정하지 않고도 시트에서 새로운 지수를 추가하거나 삭제할 수 있습니다.

## 관심종목 관리 프로세스 (v2.6.x)

1.  **관심종목_요청**: 사용자가 티커(`6400`)나 종목명만 입력합니다.
2.  **자동 보정 및 검색**: 시스템이 티커를 `006400`으로 보정하고, 비어있는 종목명을 찾아 시트에 다시 채워줍니다.
3.  **관리 시트 동기화**: `Asset + Ticker` 조합으로 중복 여부를 체크하여 `관심종목_관리` 탭에 깔끔하게 등록합니다.
4.  **Batch Update**: 수많은 종목을 한 번에 업데이트하여 API 효율을 극대화합니다.

### 2. 미국장 실시간성 강화 (Pre/After Market) 🆕
- **`prepost=True` 적용**: 한국 낮 시간(오후 4시/8시)에도 미국 프리마켓의 움직임을 반영
- **날짜 매핑 최적화**: KST 날짜 기준으로 전일 종가와 금일 장전 데이터를 유연하게 통합
  - 캘린더 제목: `[날짜] 📅 주말 (주식 시장 휴장)`
  - 주식 시장 휴장 안내 포함

### 3. 주말/휴장일 자동 감지 🆕
- **스마트 감지**: 프로그램이 자동으로 주말(토요일, 일요일)을 감지합니다
- **평일 모드**: 한국/미국 주식 + 주요 지수 데이터 수집
- **주말 모드**: 코인 데이터만 수집 (24/7 거래)
  - 주요 코인: BTC, ETH, XRP, SOL
  - 캘린더 제목: `[날짜] 📅 주말 (주식 시장 휴장)`
  - 주식 시장 휴장 안내 포함

### 4. 시트 구조 개선 🆕
- **Indices Info 컬럼 제거**: Market Summary에 모든 정보가 포함되어 중복 제거
- **간소화된 구조**: 6개 컬럼 → 5개 컬럼
  - Date
  - Market Summary (여러 줄 형식)
  - Watchlist Status
  - Unusual Stocks
  - Version

### 3. 시트 구조 관리 방식 🆕
- **새 월별 탭**: 프로그램이 최신 구조로 자동 생성
- **기존 탭**: 사용자가 구글 시트에서 직접 구조 변경
- **데이터 업데이트**: 프로그램이 자동으로 처리

### 4. 보안 개선 🆕
- **민감 정보 보호**: GitHub Actions 로그에 CALENDAR_ID 등 사용자 정보 미노출
- **진단 정보 주석 처리**: 디버깅 메시지 최소화

## 📊 주요 기능

### 1. 월별 시장 일지 자동 관리
- **동적 탭 생성**: `YYYY-MM` 형식으로 매월 새로운 탭을 자동 생성
- **일지 통합 기록**: 시장 지수, 관심종목 상태, 주의종목 정보를 하나의 행에 기록
- **여러 줄 표시**: Market Summary를 여러 줄로 표시하여 가독성 향상

### 2. 글로벌데이터 시트 개선
- **시장 현황 요약**: 상단에 오늘의 시장 현황 섹션 추가
  - Market Summary (KR, US, 환율)
  - Indices Info (주요 지수 상세)
- **주요 종목 데이터**: 하단에 주요 종목 정보 표시

### 3. 거래량 폭증 분석
- **분석 기준**: 최근 20일 평균 거래량 대비 당일 거래량이 **300%(3배) 이상**인 종목 자동 포착
- **표시**: 가격 등락과 거래량 강도를 함께 기록

### 4. 관심종목 추적 (v2.2.0 고도화)
- **동적 종목 관리**: `관심종목_요청` 시트에 Ticker나 종목명을 입력하고 `RequestEnabled`를 `TRUE`로 설정하면 자동으로 `관심종목_관리`에 반영됩니다.
- **보고서 병합 (Timing Resolution)**: 국장과 미장 업데이트가 겹칠 때 데이터가 유실되지 않도록 기존 데이터를 보존하며 현재 활성화된 시장 데이터만 병합하여 업데이트합니다.
- **시트 관리**: `관심종목_요청` 탭에서 종목 추가/삭제 시 `TickerFound`를 통해 유효성을 실시간 확인 가능합니다.

### 5. 시장 지수 및 대시보드
- **데이터 보강**: KOSPI, KOSDAQ, S&P500, NASDAQ, USD/KRW 환율 정보 수집
- **프리미엄 요약**: 캘린더 본문을 Markdown 형식으로 제공

## 🚀 GitHub Actions 수동 실행 방법

과거 데이터를 다시 채우거나(Backfill), 특정 날짜의 일지를 갱신할 때 사용하세요.

1. GitHub 레포지토리의 **[Actions]** 탭으로 이동
2. 왼쪽 목록에서 **"Daily Stock & Crypto Sync"** 워크플로우 선택
3. 오른쪽 상단의 **[Run workflow]** 버튼 클릭
4. **`Target date to sync`** 입력창에 원하는 날짜 입력
   - **형식**: `YYYY-MM-DD` (예: `2026-01-10`)
   - **비워둘 경우**: 자동으로 오늘 또는 가장 최신 거래일 데이터 수집
   - **입력 시**: 해당 날짜의 시장 데이터를 수집하여 시트 일지 생성/업데이트
