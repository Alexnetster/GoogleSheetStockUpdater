# 주식 데이터 갱신 및 월별 투자 일지 시스템 v2.7.0

자동화된 주식/코인 시트/캘린더 연동 시스템의 주요 기능과 사용법을 설명합니다.

## 🌟 최신 업데이트 (v2.7.0)

### 1. 주말 및 휴장일 시장 상태 로직 최적화 🆕
- **주말 강제 휴장 처리**: 지수 데이터 날짜가 최신이더라도 실제 요일이 토/일요일인 경우 '휴장'으로 정확히 표시합니다.
- **데이터 필터링 완화**: 기존에는 시장이 '휴장'인 경우 '오늘' 탭에서 해당 데이터가 생략되었으나, 이제는 휴장 여부와 상관없이 수집된 최신(직전 종가) 데이터를 항상 표시하여 가시성을 확보했습니다.

### 2. 로컬 검증 및 정합성 강화 (v2.6.9)
- **`tools/verify_sync.py` 도입**: 실제 시트를 수정하지 않고도 로컬에서 데이터 싱크를 검증할 수 있습니다.
- **내부 로깅 훅**: `updater.py`에 데이터 전송 직전 페이로드를 가로채는 `_log_payload` 메서드가 추가되었습니다.

## 🧪 로컬 검증 가이드 (Local Verification)

데이터 누락이나 병합 오류가 의심될 때, 수동으로 시트를 확인하는 대신 아래 절차를 통해 로컬에서 즉시 확인할 수 있습니다.

### 1. 검증 스크립트 실행
특정 날짜와 세션 모드를 지정하여 실행합니다. (기본값: 오늘, AUTO 모드)
```bash
# 1월 10일(토) 데이터 검증 (Dry-run 모드)
python tools/verify_sync.py --date 2026-01-10
```

### 2. 생성된 로그 확인
`debug_logs/{date}/` 폴더에 생성된 JSON 파일들을 통해 데이터 정합성을 확인합니다.
- **today_rows.json**: '오늘' 탭에 출력될 최종 행 데이터 (표 형식)
- **monthly.json**: 월별 일지에 기록될 통합 리포트 페이로드
- **calendar.json**: 구글 캘린더 이벤트의 제목(`summary`)과 본문(`description`)
