# 주식 데이터 갱신 및 월별 투자 일지 시스템 v2.6.9

자동화된 주식/코인 시트/캘린더 연동 시스템의 주요 기능과 사용법을 설명합니다.

## 🌟 최신 업데이트 (v2.6.9)

### 1. 로컬 검증 및 정합성 강화 🆕
- **`tools/verify_sync.py` 도입**: 실제 시트를 수정하지 않고도 로컬에서 데이터 싱크를 검증할 수 있습니다.
- **내부 로깅 훅**: `updater.py`에 데이터 전송 직전 페이로드를 가로채는 `_log_payload` 메서드가 추가되었습니다.
- **드라이 런(Dry-run) 지원**: `--real` 옵션 없이 실행 시 구글 시트 및 캘린더 쓰기 작업을 수행하지 않습니다.

### 2. 세션 기반 '오늘' 탭 레이아웃 (v2.6.8)
- **4대 세션 로그**: MORNING(모닝), MIDDAY(미드데이), CLOSE(장마감), EVENING(이브닝) 세션별로 타임스탬프와 함께 결과가 기록됩니다.
- **시장 상태 필터링**: 해당 시간대에 활성화된 시장(국장/미장)의 데이터만 선별하여 리포트합니다.

### 3. 리포트 3대 체제 & 과거 동기화 (v2.6.7)
- **섹션 재편**: 월간 리포트를 **[주요종목], [관심종목], [특이종목]** 3단계로 구성했습니다.
- **최종 상태 정책**: 과거 날짜 동기화 시, 기존 데이터를 유지하면서 신규 데이터로 병합(Merge)하여 데이터 유실을 방지합니다.

## 🧪 로컬 검증 가이드 (Local Verification)

데이터 누락이나 병합 오류가 의심될 때, 수동으로 시트를 확인하는 대신 아래 절차를 통해 로컬에서 즉시 확인할 수 있습니다.

### 1. 검증 스크립트 실행
특정 날짜와 세션 모드를 지정하여 실행합니다. (기본값: 오늘, AUTO 모드)
```bash
# 1월 9일 데이터 검증 (Dry-run 모드)
python tools/verify_sync.py --date 2026-01-09
```

### 2. 생성된 로그 확인
`debug_logs/{date}/` 폴더에 생성된 JSON 파일들을 통해 데이터 정합성을 확인합니다.
- **today_rows.json**: '오늘' 탭에 출력될 최종 행 데이터 (표 형식)
- **monthly.json**: 월별 일지에 기록될 통합 리포트 페이로드
- **calendar.json**: 구글 캘린더 이벤트의 제목(`summary`)과 본문(`description`)

### 3. 검증 항목 체크리스트
- [ ] `today_rows.json`에 지수 및 환율 정보가 포함되어 있는가?
- [ ] `monthly.json`의 리포트 본문에 누락된 종목이 없는가?
- [ ] 캘린더 이벤트의 세션 태그(예: 모닝브리핑)가 정확한가?

> [!TIP]
> **검증 도구 사용 시 주의사항**
> - 검증 도구는 관심종목 목록을 가져오기 위해 구글 시트 **읽기 권한**이 필요합니다.
> - `--real` 옵션을 주지 않는 한, 시트의 내용은 절대 변경되지 않으므로 안심하고 테스트하세요.

## 🛠️ 주요 함수 설명

### `StockDataUpdater.process_and_report(mode, manual_date)`
전체 업데이트 프로세스를 조율합니다.
1. `get_watchlist()`: 시트에서 관리 대상 종목을 가져옵니다.
2. `get_market_indices()`: 지수 및 환율을 수집합니다.
3. `update_global_data()`: '오늘' 탭을 갱신합니다.
4. `get_monthly_worksheet()` & `update()`: 월별 로그를 기록/병합합니다.
5. `create_calendar_event()`: 캘린더 이벤트를 생성합니다.
