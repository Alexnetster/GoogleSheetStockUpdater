# 주식 데이터 갱신 및 월별 투자 일지 시스템 완료

사용자 맞춤형 **월별 시장 일지**와 **고도화된 캘린더 요약** 기능을 갖춘 주식 데이터 자동화 시스템 v1.2.0 구현을 완료했습니다.

## 🌟 이번 업데이트의 주요 기능 (v1.2.0)

### 1. 월별 시장 일지 자동 관리
- **동적 탭 생성**: `YYYY-MM` 형식으로 매월 새로운 탭을 자동 생성하여 데이터를 분리 관리합니다. (가독성 증대)
- **일지 통합 기록**: 시장 지수, 관심종목 상태, 특이종목 정보를 하나의 행에 일목요연하게 기록합니다.

### 2. 거래량 폭증 분석 (Volume Spike)
- **분석 기준**: 최근 20일 평균 거래량 대비 당일 거래량이 **300%(3배) 이상**인 종목을 자동 포착합니다.
- **표시**: 가격 등락뿐만 아니라 거래량 강도를 함께 기록하여 시장의 주도주를 쉽게 파악할 수 있습니다.

### 3. 나만의 관심종목- [구글 캘린더](https://calendar.google.com/) 설정으로 이동
- 사용할 캘린더의 **'특정 사용자와 공유'** 섹션에서 서비스 계정 이메일을 추가하고 **'이벤트 변경'** 권한을 부여합니다.

## 5. 수동 실행 및 과거 데이터 복구 (Backfill)
매일 정해진 시간에 자동 실행되지만, 필요 시 특정 날짜를 지정해 직접 실행할 수 있습니다.
1.  GitHub **Actions** 탭 -> **"Daily Stock & Crypto Sync"** 선택
2.  **[Run workflow]** 클릭 -> **`Target date to sync`**에 날짜 입력 (예: `2026-01-09`)
3.  입력하지 않고 실행하면 평소처럼 '오늘' 데이터를 수집합니다.
- **우선 보고**: 캘린더 요약 및 일지 최상단에 관심종목의 현재 상태를 가장 먼저 노출합니다.

### 4. 시장 지수 및 대시보드 확장
- **데이터 보강**: KOSPI, KOSDAQ, S&P500, NASDAQ, USD/KRW 환율 정보를 모두 수집합니다.
- **프리미엄 요약**: 캘린더 본문을 Markdown 형식을 활용하여 가공된 뉴스 링크와 함께 대시보드 형태로 제공합니다.

### 4. 고도화된 날짜 처리 및 휴장일 대응 (v1.3.0)
- **대상 날짜 지정 (Backfill)**: `python updater.py 2026-01-09`와 같이 명령행 인자를 통해 과거 특정 날짜의 일지를 생성하거나 누락된 데이터를 보충할 수 있습니다.
- **주식-코인 하이브리드 로직**: 
    - **주식**: 지정된 날짜가 주말/휴장일인 경우, 자동으로 이전의 **가장 가까운 마지막 거래일** 데이터를 매핑합니다.
    - **코인**: 24시간 운영되는 특성을 반영하여 지정된 날짜의 데이터를 정확히 추출합니다.
- **중복 기록 방지 및 업데이트**: 시트에 이미 같은 날짜의 데이터가 있을 경우, 행을 추가하지 않고 **기존 내용을 최신 분석값으로 업데이트**합니다.
- **GitHub Actions 수동 날짜 입력**: 웹 인터페이스에서 특정 날짜를 지정하여 즉시 실행이 가능합니다. (상세 사용법 하단 참조)

## 🚀 GitHub Actions 수동 실행 방법 (날짜 지정)

나중에 과거 데이터를 다시 채우거나(Backfill), 특정 날짜의 일지를 갱신하고 싶을 때 사용하세요.

1.  GitHub 레포지토리의 **[Actions]** 탭으로 이동합니다.
2.  왼쪽 목록에서 **"Daily Stock & Crypto Sync"** 워크플로우를 선택합니다.
3.  오른쪽 상단의 **[Run workflow]** 버튼을 클릭합니다.
4.  새로 생긴 **`Target date to sync`** 입력창에 원하는 날짜를 입력하고 실행합니다.
    *   **형식**: `YYYY-MM-DD` (예: `2026-01-09`)
    *   **입력창을 비워둘 경우**: 자동으로 오늘 혹은 가장 최신 거래일 데이터를 가져옵니다.
    *   **입력 시**: 해당 날짜의 시장 데이터를 수집하여 시트 일지를 생성하거나 기존 기록을 업데이트하며, 캘린더 이벤트도 해당 날짜에 맞춰 갱신됩니다.

---

### 5. 데이터 발생일(Market Date) 중심 동기화 (v1.3.2)
- **자동 날짜 감지**: 프로그램 실행 시점이 아닌, 실제 데이터(KOSPI, S&P500 등)가 **마지막으로 발생한 날짜**를 기준으로 일지를 기록합니다.
  - 예: 토요일 오전 실행 시 -> 자동으로 금요일 일지를 찾아 최신 정보(미장 종가 등)로 업데이트합니다.
- **휴장일 데이터 중복 방지**: 금요일 데이터가 토요일/일요일 칸에 새로 생기는 것을 방지하여 캘린더를 깨끗하게 유지합니다.
- **Backfill 연동**: 수동으로 날짜를 입력(`python updater.py 2026-01-08`)할 경우에는 입력한 날짜를 우선적으로 처리합니다.
