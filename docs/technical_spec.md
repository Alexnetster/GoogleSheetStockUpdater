# 주식 데이터 갱신 및 분석 프로젝트 기술 명세서 (Technical Spec)

이 문서는 프로그램의 상세 설계, 데이터 구조 및 운영 로직을 설명합니다.

## 프로젝트 개요
Google Spreadsheet 및 Calendar API를 연동하여 자산별(국장, 미장, 코인) 데이터를 수집하고, 특이 종목을 분석하여 일괄된 요약본을 제공하는 자동화 시스템입니다.

## 핵심 컴포넌트 (`updater.py`)
- **API 인증**: Google 서비스 계정(`credentials.json`)을 사용하여 Sheets/Calendar API 권한 획득.
- **데이터 수집 엔진**:
    - **국장**: `FinanceDataReader`로 종목 리스트 및 전수 조사(상한가/거래량), `yfinance`로 가격 수집.
    - **미장/코인**: `yfinance`를 활용한 글로벌 데이터 수집.
    - **스크래퍼**: `BeautifulSoup`를 이용한 네이버 증권(테마/뉴스/수급) 크롤링.
- **분석기 (Analyzer)**:
    - **특이 종목**: 상한가, 거래량 급증(평균 대비 5배 등), 외국인 순매수 상위 등 자동 탐지.
    - **버퍼링 시스템**: 장중 발생하는 특이 종목을 `주의종목_버퍼`에 누적하여 데이터 소실 방지.
- **출력기 (Exporter)**:
    - **오늘 (Dashboard)**: 매번 초기화 후 최신 상태 재작성 (국가별 섹션 분리).
    - **월별 (Archive)**: 7-Column 구조 (날짜, 지수, 관심, 주요, 코인, 주의, 갱신일).
    - **캘린더**: 구글 캘린더에 섹션별 요약 이벤트 생성.

## 데이터 구조 (Google Sheets)

### 1. 오늘 (Dashboard Mode)
매 실행 시 초기화(Clear) 후 재작성됩니다.
- **구성**: 헤더(세션정보) -> 지수/환율 -> 주요종목(KR/US) -> 관심종목(KR/US) -> 코인 -> 주의종목
- **특징**: 언제 보더라도 현재 시점의 시장 상태를 국가별로 정렬하여 표시.

### 2. 월별 일지 (Archive Mode)
- **탭 이름**: `YYYY-MM` (자동 생성)
- **컬럼 구조**:
    1.  **날짜**: `YYYY-MM-DD`
    2.  **지수/환율**: 주요 지수 및 환율 요약
    3.  **관심종목**: Watchlist 요약
    4.  **주요종목**: Major 종목 요약
    5.  **코인**: Crypto 시세 요약
    6.  **주의종목**: `주의종목_버퍼` 누적 데이터 통합
    7.  **갱신날짜**: 최종 기록 시각 (Timestamp)

### 3. 주의종목_버퍼 (Buffer Mode)
- **역할**: 휘발성 특이 종목(장중 상한가 등)을 하루 동안 임시 저장을 통해 누적.
- **로직**: 날짜 변경 시 자동 초기화, 동일 종목 중복 방지.
- **컬럼**: `날짜`, `자산`, `티커`, `종목명`, `현재가`, `변동률`, `거래량`, `출처`

### 4. 관심종목_관리 (DB Mode)
사용자가 종목을 관리하는 메인 DB입니다.
- **컬럼**: `구분`(Asset), `카테고리`, `티커`, `종목명`, `테마`, `메모`, `알림가`, `시스템추천`, `전문가의견`, `정보링크`
- **입력**: 사용자가 `관심종목_요청` 탭을 통해 Add/Delete 수행.

---

## 특이 종목 선정 기준 (Filtering Criteria)
1.  **가격 급변**: 상한가(30%) 및 등락률 15% 이상.
2.  **거래량 폭증**: 500만 주 이상 & 전일/평균 대비 급증.
3.  **수급 포착**: 외국인 순매수 상위(네이버 증권).

## 자동화 스케줄링 (GitHub Actions)
- **데일리 동기화**: `08:00`(미장마감), `12:00`(국장오전), `16:00`(국장마감), `20:00`(미장프리)
- **이벤트 트리거**: `workflow_dispatch` (수동 실행), `push` (개발 반영 시)
